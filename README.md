# C+ Агент

Веб-приложение с регистрацией пользователей по e-mail и встроенным ИИ-консультантом (чат Timeweb Cloud AI Agent). Дизайн — в стиле сайта [consultant.ru](https://www.consultant.ru): светло-серый фон, фиолетовые и оранжевые акценты.

Публикуется на GitHub Pages по адресу: `https://<username>.github.io/cplusagent/`

## Возможности

- Регистрация и вход по e-mail (Supabase Auth)
- Выход из аккаунта и отображение профиля
- Чат доступен **только после входа**: до авторизации вместо чата показывается заблокированная карточка с кнопкой входа
- Встроенный полноэкранный чат-виджет ИИ-агента Timeweb Cloud — консультация открывается прямо в странице (не плавающая кнопка)
- Адаптивная вёрстка в стиле КонсультантПлюс

## Структура

```
index.html       — разметка страницы
css/style.css    — стили
js/config.js     — конфигурация Supabase (заполняется перед деплоем)
js/app.js        — логика (регистрация, вход, профиль, встраивание чата)
favicon.svg      — фавикон
```

## О чате

Чат — полноэкранный и встроен в страницу: загружается скрипт виджета `agent-chat-widget.js`, создаётся элемент `<agent-chat-widget>` с параметрами агента (ID `895689ca-80d3-46ec-b694-36c75a60b00f`, сервер `chat.timeweb.cloud`), после чего через инъекцию стилей в его shadow DOM виджет разворачивается на всю ширину карточки (560px высоты, 480px на мобильных). Кнопки сворачивания/закрытия скрыты, чтобы чат нельзя было «потерять» — он всегда доступен в секции «Консультация».

**Доступ к чату ограничен:** виджет создаётся только после успешного входа (реальная сессия Supabase или демо-вход). Пока пользователь не авторизован, в секции «Консультация» показывается заблокированная карточка с приглашением войти. После выхода виджет удаляется из страницы и доступ снова закрывается.

**Демо-вход:** пока Supabase не настроен, в карточке входа появляется блок «Войти в демо» — он имитирует регистрацию/вход, открывает чат и сохраняет сессию на время вкладки (sessionStorage). Это позволяет проверить весь сценарий до настройки бэкенда.

URL скрипта и параметры агента заданы в [js/app.js](js/app.js) (константы `CHAT_SCRIPT` и `CHAT_CONFIG`).

## Настройка Supabase (регистрация по e-mail)

1. Создайте проект на [supabase.com](https://supabase.com) (бесплатный план подойдёт).
2. В панели проекта откройте **Settings → API**.
3. Скопируйте значения **Project URL** и **anon public** в файл [js/config.js](js/config.js):

```js
window.SUPABASE_CONFIG = {
  url: "https://ваш-проект.supabase.co",
  anonKey: "eyJhbGciOi..."
};
```

4. В **Authentication → Providers** убедитесь, что включён провайдер **Email**.
5. В **Authentication → URL Configuration** укажите адрес вашего сайта (например, `https://username.github.io`).

> **Важно.** Поля можно заполнить и после публикации — приложение будет работать в «демо-режиме» (чат доступен через демо-вход, регистрация по e-mail показывает подсказку о настройке).

## Публикация на GitHub Pages

1. Создайте репозиторий с именем **`cplusagent`** на GitHub (публичный, иначе GitHub Pages не будет работать на бесплатном плане).

```bash
git init
git add .
git commit -m "C+ Агент: регистрация по e-mail и ИИ-консультант"
git branch -M main
git remote add origin https://github.com/<username>/cplusagent.git
git push -u origin main
```

2. В репозитории откройте **Settings → Pages**.
3. В разделе **Build and deployment → Source** выберите **Deploy from a branch** и укажите ветку `main`, папку `/ (root)`.
4. Сохраните — сайт будет доступен по адресу `https://<username>.github.io/cplusagent/`.

> Проект не использует систему сборки: для GitHub Pages достаточно выложить файлы из корня репозитория.

## Безопасность

- `anon`-ключ Supabase — публичный ключ, предназначенный для использования в браузере. Однако убедитесь, что в **Supabase → Authentication → Policies** доступ к таблицам данных ограничен (по умолчанию для новых проектов доступ закрыт).
- Не храните в [js/config.js](js/config.js) секретные ключи — только `anon public`.
